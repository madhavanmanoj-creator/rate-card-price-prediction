# Capstone Project 24.1: Final submission

**Submit:** the link to the GitHub repository for this project.

Paste this link into the submission area (replace with your own address after upload):

    https://github.com/<your-github-username>/<repository-name>

## What a reviewer will find
- `README.md` at the top of the repository: the plain-language report, with links to the notebooks.
- `notebooks/`: four notebooks that run top to bottom without errors (cleaning, exploration, modelling, findings).
- `test_data/`: five Excel sheets with 50 or more rows each.
- `tests/`: automated checks.

## Before you press submit
1. Open the repository link in a private browser window and confirm you can see the README without signing in.
2. Click each notebook link in the README and confirm it opens.
3. Confirm the repository is set to Public.
